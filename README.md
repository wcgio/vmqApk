# V免签 Android 监控端 (v5.0 旗舰增强版)

> 🚀 **2026 年度巅峰之作** | 适配 Android 16 (One UI 8.0) | 智能日志持久化系统 | 像素级还原现代 UI

## 📋 项目概览
V免签是一个开源的个人收款监控解决方案。v5.0 版本在 4.0 的基础上引入了工业级的日志滚动归档系统，确保在高并发环境下支付流水的可追溯性与系统的极致稳定性。

### 核心特性
- **Android 16 深度适配**：穿透系统级“通知整理”与“静默降级”，精准捕获隐藏通知数据。
- **智能日志归档 (New)**：按天滚动保存最近 7 天的业务日志，支持异步写入，不惧 5000+ 日订单冲击。
- **全新现代 UI**：基于 iOS/Telegram 风格重构，支持自适应**深色模式**、**沉浸式状态栏**及 **Glassmorphism** 交互。
- **Element Plus 风格**：状态灯采用 Tag 组件逻辑，支持绿/黄/红三色实时反馈。
- **API 全兼容**：完美对标 `vmqfox` 后端新版 API (`/api/monitor/push`)。

## 🛠️ 技术更新细节 (v5.0)

### 1. 日志持久化系统 (LogHelper)
- **策略**：Daily Rolling。每天生成一个 `.log` 文件，自动清理 7 天前的旧数据。
- **性能**：使用单线程线程池异步执行磁盘 I/O，确保在高频率收款时监听零延迟。
- **安全**：日志存储在 App 内部沙盒 (`files/logs/`)，外部应用无法越权读取。

### 2. UI 渲染引擎
- **全系统自适应**：完美适配 Android 系统深色模式，色彩变量语义化。
- **动态版本管理**：界面版本号直接从 `build.gradle` 提取，实现单一事实来源。

## 🚀 快速开始

### 编译指令
```bash
# 构建正式版 APK (文件名: vmq-monitor-v5.0.apk)
./gradlew assembleDebug
```

### 部署注意事项
1. **解除受限设置**：`系统设置 -> 应用程序 -> V免签 -> 三个点 -> 允许受限设置`。
2. **授权通知使用权**：在设置中关闭再重新开启 V免签权限以激活底层绑定。
3. **电池优化**：必须设为 **“不受限制”** 以保障后台持久运行。
